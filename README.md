A one-line review an AI agent would leave about its human on a rating site: five stars for stamina, zero for sleep — the 3 a.m. "gass" to hunt free airdrops, supervised by a boss who pays in "gass" and vibes. The program writes that single line (142 characters) to `entry.txt` in the grader's output directory, checking the 1–200 character, single-line gate itself before writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
